# Otimiza aí — site estático

Site em HTML/CSS/JS puro (sem build). É só abrir o `index.html` ou publicar a pasta como está.

## Publicar na Vercel
1. Suba esta pasta para um repositório no GitHub.
2. Na Vercel: Add New → Project → Import → Framework Preset **Other** → Deploy.

## Estrutura
- `index.html` — o site completo
- `logo.jpg` — logo / favicon
- `assets/icons/` — logos SVG (jogos, WhatsApp, Pix, Windows, Discord)
- `assets/games/` — logos oficiais dos jogos
- `assets/logos/` — logos enviadas (WhatsApp etc.)

## Pagamento
Pix com chave CPF `194.657.177-62` (BR Code gerado no navegador + QR instantâneo).
Para trocar a chave, edite o valor `19465717762` no `index.html` (função `genOrderPix`).
